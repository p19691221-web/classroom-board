# 課堂小黑板

在教室觸控黑板、平板或電腦的瀏覽器直接打開就能用的小黑板。不用安裝，不用登入，一個 `index.html` 就是全部。

網址：https://p19691221-web.github.io/classroom-board/

## 功能

- **書寫**：白、黃、粉紅、藍四色粉筆，三種粗細，板擦、復原（Ctrl+Z）、打字。每根手指各畫各的，兩個人可以同時上台寫。
- **多頁**：上一頁、下一頁、新增頁；「方格」可打開格線。
- **計時**：1／3／5／10 分鐘或自訂，倒數大字顯示在黑板右上角，時間到響鈴。
- **抽籤**：名單填「1-30」代表座號 1 到 30，也可以一行一個名字。預設抽過的不再抽。
- **水痕故事**：從「[水泥地水痕](https://p19691221-web.github.io/soft-shelf/works/shuihen/)」挑一則四格故事，可以直接在黑板上播放水管畫畫的過程，或把四格文字抄到新的一頁，當課前暖身或討論題。這項需要網路。
- **班級群組**：貼上班上自己那份「我們的地方」的網址，就能從黑板一鍵打開，或把 QR code 和網址秀在黑板上讓學生用手機掃。QR code 在頁面內產生，不用連外。還沒有的話，可以用 [our-space-template](https://github.com/p19691221-web/our-space-template) 建一份。網址只存在這台裝置的瀏覽器裡。
- **訂便當／飲料團購**：用「[收款結算小幫手](https://p19691221-web.github.io/bento-calc/bento.html)」登記全班的訂單、算誰該付多少。可以直接在黑板上打開讓全班看同一份清單；也可以貼上 Google 表單或共用 Excel 的網址，把 QR code 秀在黑板上讓同學用手機填，最後批次貼回小幫手。
- **下課筆記**：「下載全部（PDF）」把所有頁面合成一個 PDF，一頁黑板一頁；也可以單張下載 PNG。PDF 在頁面內產生，不需要網路。
- 黑板內容存在這台裝置的瀏覽器裡，重新打開還在；換裝置或清除瀏覽資料就不會有。

## 沒有做的部分

完整的「AI 黑板」還包括手寫與公式辨識、語音轉文字、課堂專注度分析和雲端同步。這些需要 API 金鑰、後端和硬體驅動，不在這個小工具的範圍內。這個工具示範的是另一條路：用 AI 寫出能在黑板瀏覽器直接開的單一網頁。

## 設定

1. 把 `index.html` 和這份 README 放進公開 repo `classroom-board`。
2. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`。
3. 一兩分鐘後打開上面的網址。
